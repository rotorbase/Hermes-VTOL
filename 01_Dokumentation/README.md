# 01_Dokumentation

Vollständige Projektdokumentation, gegliedert nach Dokumenttyp.

## Inhalt

| Ordner | Zweck |
| -------- | ------- |
| **Lastenheft/** | Anforderungskatalog (Ziel: was wollen wir bauen) — siehe v1.1 |
| **Pflichtenheft/** | Technische Spezifikation (Wie setzen wir es um) — folgt nach CAD-Konzept |
| **SORA/** | Specific Operations Risk Assessment für EU-Zulassung |
| **Zulassung/** | EASA-Anträge, Konformitätsnachweise, FAA-Part-107-Waiver |
| **Protokolle/** | Besprechungsprotokolle, Review-Notizen, Entscheidungs-Logs |

## Dokument-Workflow

1. **Lastenheft** = WAS (Anforderungen)
2. **Pflichtenheft** = WIE (Umsetzung)
3. **SORA** = DARF ICH (Risikobewertung)
4. **Zulassung** = BEHÖRDE (Antrag & Nachweis)
