## 🔗 Wofür sind die Verordnungen?

### 🔴 EU-VO 2019/947 — **das Hauptdokument**

**Direkter Link:** <https://eur-lex.europa.eu/eli/reg/2019/947/oj>

**Beantwortet:**

| Frage | Ja/Nein |
| ------- | -------- |
| Brauche ich eine Registrierung? | **Ja** (EU-Operator-Register) |
| In welche Klasse fällt meine Drohne? | Specific (16 kg + SAR) |
| Brauche ich eine Erlaubnis? | **Ja** (SORA-Analyse) |
| Muss ich Pilot sein? | **Ja** (Fernpilot-Zeugnis A1/A2/A3) |

### 🔴 EU-VO 2019/945 — **die Drohne selbst**

**Direkter Link:** <https://eur-lex.europa.eu/eli/reg/2019/945/oj>

**Beantwortet:**

| Frage | Ja/Nein |
| ------- | -------- |
| Braucht meine Drohne eine CE-Kennzeichnung? | **Ja**, je nach Klasse |
| Welche technischen Anforderungen? | Stückzahl, Sicherheit, Funk |
| Klasse C0-C6 — was muss welche können? | Details in Annexen |

### 🔴 EU-VO 785/2004 — **Versicherung**

**Direkter Link:** <https://eur-lex.europa.eu/eli/reg/2004/785/oj>

**Beantwortet:**

| Frage | Antwort |
| ------- | --------- |
| Mindest-Deckungssumme? | 750.000 Sonderziehungsrechte (SZR) |
| Was ist gedeckt? | Personen- und Sachschäden |
| Gilt das auch für Hobby? | **Ja, ab gewerblichem Einsatz** |

### 🟠 EU-VO 2021/664 — **U-space**

**Direkter Link:** <https://eur-lex.europa.eu/eli/reg/2021/664/oj>

**Beantwortet:**

| Frage | Wer |
| ------- | ----- |
| Was ist U-space? | Lufträume mit Drohnen-Verkehrsmanagement |
| Wer betreibt U-space? | U-space-Service-Provider (USSP) |
| Wo wird mein Flug freigegeben? | Über USSP-System |
