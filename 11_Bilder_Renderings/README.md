# 11_Bilder_Renderings

Visuelle Dokumentation.

## Inhalt

| Ordner | Zweck |
| -------- | ------- |
| **CAD_Renderings/** | Exportierte Renderings aus Fusion 360 |
| **Prototyp_Fotos/** | Fotos vom realen Prototypen-Bau |
| **Marketing/** | Präsentationen, Konzeptbilder |

## Namens-Konvention

`<Komponente>_<Winkel>_<Datum>.<ext>`

Beispiel: `Hermes-VTOL_vorne-rechts_2026-09-22.png`
Beispiel: `Rumpf_innen_2026-09-22.jpg`

## Empfohlene Auflösungen

- CAD-Renderings: 1920×1080 (Präsentation) + 4K (Print)
- Prototyp-Fotos: Original + komprimiertes Web-Format (max. 2 MB)
